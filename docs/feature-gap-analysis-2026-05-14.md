# BMAD 功能差距分析报告

> 分析日期：2026-05-14
> 项目：blank-wallpaper-society
> 分析范围：现有功能 vs 理想功能

---

## 🔴 高优先级缺失功能

### 1. 社交登录
**现状：** 仅支持邮箱+密码注册登录
**影响：** 高 — 用户注册门槛高，流失率大
**建议：** 接入 Google、GitHub、微信 OAuth 登录
**工作量：** 中（NextAuth.js 已有 OAuth 支持）

### 2. 密码重置
**现状：** 无忘记密码/重置密码流程
**影响：** 高 — 用户无法自助恢复账号
**建议：** 实现邮箱验证码重置密码流程
**工作量：** 中（需邮件发送服务）

### 3. 用户设置页面
**现状：** 个人主页只有统计数据，无设置入口
**影响：** 高 — 用户无法修改密码、头像、昵称
**建议：** 新增 `/settings` 页面，包含：
- 修改头像/昵称
- 修改密码
- 账号绑定（OAuth）
- 通知偏好
**工作量：** 中

### 4. 评论系统
**现状：** 图片详情页无评论区
**影响：** 高 — 缺乏用户互动和社区氛围
**建议：** 图片详情页底部增加评论区
- 支持文字评论
- 支持回复/嵌套评论
- 评论审核（管理员可删除）
**工作量：** 大（需建表 + API + UI）

### 5. 下载历史
**现状：** 下载日志已记录，但用户看不到自己的下载记录
**影响：** 中 — 用户无法追溯下载过的壁纸
**建议：** 在个人主页新增「下载历史」Tab
**工作量：** 小（已有日志表，只需前端展示）

### 6. 通知系统
**现状：** 无任何通知机制
**影响：** 中 — 用户不知道图片审核结果、新粉丝等
**建议：** 实现站内通知：
- 图片审核结果通知
- 新收藏/关注通知
- 评论回复通知
**工作量：** 大（需建通知表 + 实时推送）

---

## 🟡 中优先级缺失功能

### 7. 用户关注系统
**现状：** 无用户关注功能
**影响：** 中 — 无法形成创作者-粉丝关系
**建议：** 增加关注/取关功能，关注者 Feed 流
**工作量：** 中

### 8. 分享功能
**现状：** 无社交分享按钮
**影响：** 中 — 限制了自然传播
**建议：** 接入 Web Share API + 微信/微博分享链接
**工作量：** 小

### 9. 搜索建议/自动补全
**现状：** 搜索为简单 LIKE 查询
**影响：** 中 — 搜索体验不完整
**建议：** 实现搜索建议下拉、热门搜索词展示
**工作量：** 中

### 10. 相似图片推荐
**现状：** 图片详情页无相关图片推荐
**影响：** 中 — 降低用户停留时长
**建议：** 在图片详情页底部展示「相似壁纸」
**工作量：** 中（基于标签/分类/颜色相似度）

### 11. 标签管理
**现状：** tags 以 JSON 字符串存储，无标签系统
**影响：** 中 — 无法按标签浏览、无法标签建议
**建议：** 建立独立 tags 表 + 标签云页面
**工作量：** 中

### 12. 水印保护
**现状：** 图片直接展示原图 URL
**影响：** 中 — 图片容易被盗用
**建议：** 上传时自动叠加水印，预览图加水印
**工作量：** 中（Sharp 叠加水印）

### 13. SEO 优化
**现状：** 未设置 meta 标签、Open Graph、结构化数据
**影响：** 中 — 搜索引擎收录差
**建议：** 
- 添加 `<head>` meta 标签
- Open Graph / Twitter Card
- 生成 sitemap.xml
- JSON-LD 结构化数据
- robots.txt
**工作量：** 中

### 14. 图片 EXIF 信息展示
**现状：** 无 EXIF 数据
**影响：** 低-中 — 摄影爱好者关注此信息
**建议：** 图片详情页展示 EXIF（相机、ISO、光圈等）
**工作量：** 小（Sharp 可提取）

---

## 🟢 低优先级/锦上添花

### 15. PWA 支持
**现状：** 无 manifest.json / Service Worker
**建议：** 添加 PWA 支持，用户可将网站添加到桌面
**工作量：** 小

### 16. 国际化 (i18n)
**现状：** 全中文界面
**建议：** 接入 next-intl 实现多语言
**工作量：** 大

### 17. 批量上传
**现状：** 仅单张上传
**建议：** 支持多文件拖拽批量上传
**工作量：** 中

### 18. AI 功能
**现状：** 无 AI 能力
**建议：** 
- AI 标签自动生成（上传时自动打标签）
- 以图搜图（图片相似度搜索）
- AI 壁纸生成
**工作量：** 大

### 19. 暗黑模式
**现状：** 需要验证
**建议：** 实现主题切换（亮色/暗色/跟随系统）
**工作量：** 中

### 20. 关于/帮助/协议页面
**现状：** 无法律和帮助页面
**建议：** 添加：
- 关于我们
- 服务条款
- 隐私政策
- 常见问题 FAQ
**工作量：** 小

### 21. 管理后台增强
**现状：** 基础管理功能
**建议：** 
- 操作审计日志
- 数据导出（CSV）
- 内容统计图表
**工作量：** 中

### 22. 缓存与性能优化
**现状：** 仅 rankings/recommendations 有内存缓存
**建议：** 
- Redis 缓存层
- 图片 CDN 加速
- 数据库查询优化
- ISR/SSG 静态生成
**工作量：** 中-大
