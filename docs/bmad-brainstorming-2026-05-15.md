## 二、全新发现的缺失/可扩展功能

> 以下功能在之前的 feature-gap-analysis 中未提及或提及不够深入

### 🔴 A. 核心体验缺失（高优先级）

#### A1. 壁纸预览适配体验 — 设备实时预览
**现状：** 多分辨率下载已有，但用户无法在下载前预览壁纸在自己设备上的效果  
**建议：** 新增「设备预览」功能  
- 在 Lightbox 中嵌入手机/平板/桌面 mockup 框架  
- 实时展示壁纸在目标设备上的裁剪效果  
- 用户可拖拽调整壁纸在设备中的位置  
**影响：** 高 — 直接影响下载转化率，减少"下载后发现不合适"的流失  
**工作量：** 中  

#### A2. 壁纸定时更换功能
**现状：** 无任何定时更换壁纸的机制  
**建议：**  
- PWA/桌面端：定时推送新壁纸并自动更换  
- Web端：生成「每日壁纸」订阅链接（RSS/邮件）  
- 移动端：与壁纸引擎集成（Wallpaper Engine、Muzei 等）  
**影响：** 高 — 壁纸类产品核心使用场景，目前完全缺失  
**工作量：** 中-大  

#### A3. 上传流程优化 — 智能填充
**现状：** 上传需手动填写标题、分类、标签、描述，流程繁琐  
**建议：**  
- AI/规则自动识别：根据文件名、图片内容自动建议标题和分类  
- 自动提取 EXIF 数据填充拍摄信息  
- 标签智能推荐（基于已有标签库和图片色彩）  
- 色彩自动提取（已有 extract-color API，应集成到上传流程）  
**影响：** 高 — 降低上传门槛，提升内容供给  
**工作量：** 中  

#### A4. 图片去重检测
**现状：** 无去重机制，同一壁纸可能被多次上传  
**建议：**  
- 上传时计算图片 perceptual hash（pHash）  
- 与已有图片对比，相似度 >95% 标记为重复  
- 管理后台展示重复组，可批量合并/删除  
**影响：** 高 — 内容质量的核心保障  
**工作量：** 中  

### 🟡 B. 社区/社交增强（中优先级）

#### B1. 用户等级与成就系统
**现状：** 用户只有角色（普通/管理员），无成长体系  
**建议：**  
- 等级系统：基于上传数、下载量、被收藏数计算经验值  
- 成就徽章：首次上传、百次下载、连续签到等  
- 创作者认证：优质创作者专属标识  
- 等级特权：高等级用户上传免审、更大存储空间  
**影响：** 中-高 — 提升用户粘性和活跃度  
**工作量：** 中  

#### B2. 动态/Feed 流增强
**现状：** 有关注系统和 `/api/feed`，但 Feed 只有关注者的图片  
**建议：**  
- 混合 Feed：关注者 + 推荐 + 热门  
- 支持 Feed 类型筛选  
- 加入"猜你喜欢"穿插推荐  
- 支持图片卡片互动（收藏、分享）直接在 Feed 中完成  
**影响：** 中 — 增加用户停留时长  
**工作量：** 中  

#### B3. 私信系统
**现状：** 用户之间无直接通讯方式  
**建议：**  
- 简单私信功能（文字 + 图片）  
- 创作者可被咨询（如合作邀请）  
- 管理员可群发通知  
**影响：** 中 — 社区完整度提升  
**工作量：** 大  

#### B4. 活动与挑战赛
**现状：** 无任何运营活动机制  
**建议：**  
- 每周/每月主题挑战赛（如"最佳日落壁纸"）  
- 用户投稿参赛，社区投票评选  
- 获奖作品上首页推荐  
**影响：** 中 — 活跃社区氛围，增加 UGC 产出  
**工作量：** 中  

### 🟢 C. 技术与架构扩展（低-中优先级）

#### C1. 爬虫管理增强 — 管理后台可视化
**现状：** 爬虫通过 Python 脚本手动执行，管理后台 CrawlTab 仅展示日志  
**建议：**  
- 管理后台新增「爬虫任务管理」：  
  - 可视化创建爬虫任务（选源 → 选分类 → 设置数量）  
  - 任务队列 + 进度条实时展示  
  - 定时任务（cron）自动爬取  
  - 爬取结果预览 + 批量审核入库  
**影响：** 中 — 内容运营效率大幅提升  
**工作量：** 大（需任务队列系统）  

#### C2. 图片变体自动生成
**现状：** 多分辨率下载时实时 resize，无预生成  
**建议：**  
- 上传时自动生成多分辨率变体（mobile/desktop/tablet/ultrawide）  
- 生成缩略图（不同尺寸用于列表/详情/搜索结果）  
- 存储到 MinIO，下载直接返回预生成文件  
- 减少 Sharp 实时处理压力  
**影响：** 中 — 下载速度和服务器负载  
**工作量：** 中  

#### C3. 全文搜索增强
**现状：** MySQL LIKE 查询，搜索质量差  
**建议：**  
- 接入 Meilisearch / Elasticsearch  
- 支持中文分词  
- 搜索结果按相关度排序  
- 搜索历史 + 热门搜索  
**影响：** 中 — 搜索体验质变  
**工作量：** 中-大  

#### C4. API 速率限制与计量
**现状：** V1 API 无速率限制  
**建议：**  
- 基于 API Key 的速率限制（如 100次/小时 免费版）  
- 用量统计仪表盘  
- API 套餐（免费/专业/企业）  
**影响：** 中 — API 可商业化基础  
**工作量：** 中  

### 🔵 D. 商业化与创新功能

#### D1. 创作者收益分成
**现状：** 创作者无任何收益机制  
**建议：**  
- 付费壁纸（创作者设定价格）  
- 打赏功能  
- 会员订阅解锁高质量壁纸  
**影响：** 高 — 吸引优质创作者入驻  
**工作量：** 大（需支付系统）  

#### D2. AI 壁纸生成
**现状：** 无 AI 生成能力  
**建议：**  
- 集成 Stable Diffusion / DALL-E API  
- 文字描述生成壁纸  
- 风格迁移（上传照片 → 转为艺术风格壁纸）  
- AI 修复/超分辨率（低分辨率壁纸增强）  
**影响：** 高 — 差异化竞争点  
**工作量：** 大  

#### D3. 壁纸社区主题/日历集成
**现状：** 编辑器有日历工具，但与壁纸展示脱节  
**建议：**  
- 「日历壁纸」功能：每月自动生成含日历的壁纸  
- 节日主题壁纸合集自动推送  
- 壁纸与日期联动（如春天自动推荐花卉壁纸）  
**影响：** 中 — 壁纸使用场景深化  
**工作量：** 中  

#### D4. 嵌入式小组件
**现状：** 无对外嵌入能力  
**建议：**  
- 提供嵌入式壁纸展示组件（类似 Unsplash Embed）  
- 博客/网站可直接嵌入「每日壁纸」小组件  
- 带品牌水印 + 回链，引流效果  
**影响：** 中 — 自然流量增长  
**工作量：** 中

## 五、竞品参考与创新点

| 竞品 | 核心优势 | 我们可借鉴的 |
|------|----------|-------------|
| Unsplash | 高质量 + 社区 + API 生态 | 嵌入式小组件、API 套餐、创作者统计 |
| Wallhaven | 分类丰富 + 搜索强大 | 搜索过滤器、标签系统、高级筛选 |
| Pexels | 免费 + 商用授权 | 授权类型标记、商用许可说明 |
| Pinterest | 发现机制 + 个性化推荐 | Pin Board（类似合集）、视觉搜索 |
| Wallpaper Engine | 动态壁纸 + 社区 | 动态壁纸支持、壁纸市场 |

### 核心差异化方向
1. **色彩搜索** — 已有，继续深化（色彩渐变搜索、配色方案推荐）
2. **设备适配预览** — 无竞品有此功能，蓝海
3. **AI + 壁纸** — 生成 + 修复 + 风格迁移
4. **中文壁纸社区** — 面向中文用户，本地化内容
