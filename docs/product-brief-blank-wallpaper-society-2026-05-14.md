# BMAD Product Brief — blank-wallpaper-society

> 生成日期：2026-05-14
> 项目级别：Level 2（中等复杂度）
> 项目类型：Web 应用（Next.js）

## 1. 产品概述

一个 Pinterest 风格的壁纸图库/图片社区平台。用户可浏览、搜索、上传、收藏壁纸，支持色彩搜索、排行榜、合集管理、图片编辑等功能。

## 2. 目标用户

- **普通用户**：寻找壁纸、收藏美图、探索灵感
- **创作者/摄影师**：上传作品、展示个人主页、积累粉丝
- **管理员**：审核内容、管理用户、查看数据统计

## 3. 核心价值主张

- 高质量壁纸聚合平台
- 色彩搜索（按主色调找图）
- 多分辨率下载（手机/平板/桌面）
- 图片在线编辑（裁剪/滤镜/文字/日历）

## 4. 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | Next.js 16, React 19, TypeScript, Tailwind CSS 4, Framer Motion |
| 后端 | Next.js API Routes, NextAuth.js |
| 数据库 | MySQL (Aliyun RDS) |
| 存储 | MinIO 对象存储 |
| 图片处理 | Sharp |
| UI 组件 | Radix UI, shadcn/ui, Lucide Icons |
| 设计系统 | Pinterest 风格（红色品牌色、Pin Sans 字体、Masonry 网格） |
