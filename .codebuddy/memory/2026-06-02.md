## 下载分辨率面板遮挡优化

**问题**：图片详情页（`ImageDetailClient`）中分辨率选择使用内联展开方式（inline expand），在侧边栏流式布局中容易被其他内容遮挡；Lightbox 中分辨率面板虽有 fixed 定位但缺少最大高度约束。

**修复**：
1. **`src/app/images/[id]/ImageDetailClient.tsx`** — 将内联分辨率网格改为 `position: fixed` 的浮窗弹层，定位在"选择分辨率"按钮上方，带半透明遮罩点击外部关闭
2. **`src/components/Lightbox.tsx`** — 下载面板增加 `maxHeight` 动态计算（基于按钮上方可用空间），整体改为 `flex flex-col` 布局，分辨率列表自动滚动，header 和原图按钮始终可见（`shrink-0`）
3. **`src/components/Lightbox.tsx`** — 修复下载面板贴右问题：ref 从外层 div 改为直接绑定按钮（`HTMLButtonElement`）精确定位；用 `useLayoutEffect` + `downloadPanelRef` 渲染后动态测量面板实际宽度做水平边界 clamp，避免硬编码 288px；加 `max-w-[calc(100vw-1rem)]` 自适应窄屏
4. **`src/app/images/[id]/ImageDetailClient.tsx`** — 同样加入 `useLayoutEffect` 动态水平边界检测 + `max-w-[calc(100vw-1rem)]`，确保任意设备上分辨率浮窗都不超出视口

## 每日精选图片模糊+显示不全修复

**问题**：首页 `DailyWallpaperCard` 中每日精选图片模糊且被裁剪。
- 模糊原因：优先使用 `thumbnail_url`（缩略图）而非原图 URL，且 `sizes` 属性只请求 80vw 宽度
- 裁剪原因：桌面端使用 `object-cover` 裁切图片

**修复** (`src/components/DailyWallpaperCard.tsx`)：
1. 第137行：改为优先使用 `currentImage?.url`（原图），`thumbnail_url` 作为降级兜底
2. 第173行：移除 `sm:object-cover sm:object-center`，统一使用 `object-contain` 完整展示图片
3. 第174行：`sizes` 从 `80vw` 调整为 `(max-width: 768px) 100vw, (max-width: 1200px) 90vw, 1200px` 请求更高分辨率

**进一步优化**：纯色背景填充效果太丑 → 改为双层图片设计：
- 底层：同一张图片的 `object-cover + blur-2xl + opacity-50 + saturate-[1.2]` 模糊放大版本填充空白
- 暗色叠加层：`bg-black/30` 防止模糊背景过亮
- 顶层：`object-contain` 清晰完整展示原图
- 效果类似 Apple TV / YouTube 视频预览模式

## 自适应爬虫修复 (crawl_with_scrapling.py)

### Bug 1：altcha 库可选但导致脚本退出
- **问题**：第 56 行在 `altcha` 导入失败时错误调用 `sys.exit(1)`，但 altcha 是可选依赖
- **修复**：移除 `sys.exit(1)`，同时补充 `requests` 库导入失败时缺失的 `sys.exit(1)`（requests 是必需依赖）

### Bug 2：懒加载图片提取错误（bizihu.com 爬取不对）
- **问题**：爬取的图片是小程序码、表情包等 UI 元素，而非壁纸
  - `_pick_best_image_url` 中 `src` 优先于 `data-src`，但懒加载的 `src` 通常是占位图（1x1 透明像素）
  - 缺少 `data-original`、`data-lazy-src` 等懒加载属性支持
  - bizihu.com 是 JS 动态渲染，必须用隐身浏览器模式
- **修复**（5 处改动）：
  1. **`_is_placeholder_url`**：新增占位图检测（data: URI、1x1 像素、loading 骨架等）
  2. **`_pick_best_image_url`**：重写优先级 — srcset → 懒加载(data-src/data-original) → src(非占位图) → data-bg CSS背景
  3. **`_extract_img_tags`**：扩展读取 data-original、data-lazy-src、data-bg、data-background 等属性；新增 URL 尺寸二次过滤
  4. **bizihu 专用规则**：精准匹配 `img.lazyload[data-original]`（bizihu 壁纸=src占位+data-original=zhimg URL）；新增 `_is_ui_class` 过滤 logo/icon 等非壁纸 class
  5. **`_fetch_page`**：已知 JS 渲染站点(bizihu/wallhaven/unsplash/pexels/pixabay)自动强制 stealthy 模式
  6. **URL 过滤增强**：新增 weixin/wechat/wxacode/mini-program/emoticon/smiley/advert 等拦截词

### Bug 3：Chromium stealthy 模式无法启动

  2. **`_pick_best_image_url`**：重写优先级 — srcset → 懒加载(data-src/data-original) → src(非占位图) → data-bg CSS背景
  3. **`_extract_img_tags`**：扩展读取 data-original、data-lazy-src、data-bg、data-background 等属性；新增 URL 尺寸二次过滤
